# Track0 · 기타 연습

YouTube 원곡을 틀어 놓고 연습할 때 쓰는 웹앱입니다.
구간 반복, 재생 속도 조절, 그리고 **영상에 맞춰 도는 메트로놈**을 한 화면에서 쓸 수 있습니다.

👉 **바로 열기: https://schatten97.github.io/track0/**

설치할 것은 없습니다. 휴대폰과 PC 브라우저에서 모두 동작합니다.

## 1. 시작하기

1. 위 주소를 엽니다.
2. 맨 위 입력칸에 YouTube 링크를 붙여넣고 **열기**를 누릅니다.
   - `youtube.com/watch?v=…`, `youtu.be/…`, Shorts 링크, 영상 ID(11자리)를 모두 인식합니다.
   - 링크에 시작 시간(`?t=90`)이 있으면 그 위치부터 시작합니다.
3. 한 번 연 곡은 입력칸 아래 **최근 목록**에 남아서, 다음부터는 눌러서 바로 열 수 있습니다.

### 휴대폰 홈 화면에 추가하기

앱처럼 아이콘으로 실행할 수 있습니다.

- **iPhone (Safari):** 공유 버튼 → **홈 화면에 추가**
- **Android (Chrome):** 메뉴(⋮) → **홈 화면에 추가**

### 가장 빠른 연습 흐름

1. 곡을 열고 재생합니다.
2. 연습할 부분 시작에서 **A 지정**, 끝에서 **B 지정**을 누릅니다. 휴대폰 아래쪽 바의 B 지정은 반복까지 바로 켜 주고, PC에서는 **⟳ 반복**(또는 `L`)을 눌러 켭니다.
3. **속도** 탭에서 70~80%로 늦춥니다.
4. **메트로놈** 탭에서 박자에 맞춰 **TAP**을 4번 이상 누르고, 하단의 **♩**로 메트로놈을 켭니다.

## 2. 화면 구성

### 휴대폰

| 위치 | 내용 |
|---|---|
| 위쪽 (스크롤해도 고정) | 영상, 타임라인 |
| 가운데 | **구간 반복 / 속도 / 메트로놈** 탭 |
| 아래쪽 바 | A 지정 · B 지정 · ▶ 재생 · **A로 이동** · 반복 · 메트로놈 |

- 자주 쓰는 동작은 엄지로 닿는 **아래쪽 바**에 모여 있습니다.
- 위치를 찍는 **A 지정 · B 지정**은 왼쪽(점선 상자), 구간 처음으로 돌아가는 **A로 이동**은 재생 버튼 오른쪽의 파란 버튼입니다. A로 이동 버튼에는 A 위치 시간(예: `A로 0:20`)이 표시되고, A가 없으면 `처음으로`가 표시됩니다.
- 휴대폰을 **가로**로 돌리면 왼쪽에 영상, 오른쪽에 설정이 나옵니다. 가로 화면에서는 링크 입력칸이 숨겨지니, 다른 곡을 열려면 세로로 돌려 주세요.

### PC (화면 폭 900px 이상)

왼쪽에 영상·타임라인·구간 반복, 오른쪽에 속도·메트로놈·단축키가 한 번에 보입니다.

### 타임라인

- **탭/클릭:** 그 위치로 이동
- **끌기:** 끈 범위가 A–B 구간이 되고 바로 반복 시작
- **A·B 핸들 끌기:** 구간 경계 조정
- **전체 / 구간** 버튼: 곡 전체를 보거나, A–B 구간만 확대해서 봅니다. 확대하면 박자 눈금(긴 선 = 마디 첫 박)과 싱크 포인트(주황색 ▲)가 보입니다.
- **-5s / +5s:** 5초 뒤로 / 앞으로

## 3. 구간 반복

| 기능 | 설명 |
|---|---|
| **지금 = A / 지금 = B** | 현재 재생 위치를 구간 시작/끝으로 지정 |
| 시간 입력칸 | `1:23.45` 형식으로 직접 입력 가능 |
| **-1s · -0.1 · +0.1 · +1s** | A·B를 미세 조정 |
| **⟳ 반복** | 구간 반복 켜기/끄기. 켜져 있으면 B에 닿는 순간 A로 돌아갑니다 |
| **지우기** | A·B 삭제 |
| **박에 스냅** | A·B를 지정할 때 가장 가까운 박에 딱 맞춰 줍니다. 메트로놈과 함께 쓰면 반복이 깔끔해집니다 |
| **카운트인** | 반복이 다시 시작되기 전에 메트로놈으로 1~2마디를 세어 줍니다. 화면에 1·2·3·4가 크게 표시됩니다 |
| **반복 n회** | 이번에 몇 번 반복했는지 표시 |

### 구간 저장

**＋ 현재 구간 저장**을 누르고 이름(예: "인트로 리프", "솔로 1")을 붙이면 목록에 남습니다.

- 목록에서 누르면 그 구간으로 이동해 바로 반복합니다.
- ✎ 이름 변경, ✕ 삭제
- 구간은 **곡마다 따로** 저장됩니다.

## 4. 재생 속도 · 스피드 트레이너

### 재생 속도

- 슬라이더 또는 **－5% / ＋5%** 버튼으로 25%~200% 사이에서 5% 단위로 조절합니다.
- 50~100% 사이 자주 쓰는 속도는 버튼으로 바로 고를 수 있습니다.
- 음 높이는 그대로 유지되고 빠르기만 바뀝니다 (YouTube 기본 재생 속도 기능을 사용).

### 스피드 트레이너

구간을 정해진 횟수만큼 반복할 때마다 속도를 조금씩 올려 줍니다.

| 항목 | 의미 | 예 |
|---|---|---|
| 시작 % | 처음 속도 | 70 |
| 증가 % | 한 번에 올릴 양 | 5 |
| 매 N회 | 몇 번 반복할 때마다 올릴지 | 3 |
| 목표 % | 여기까지 올라가면 멈춤 | 100 |

위 예시라면 70%로 3번 → 75%로 3번 → … → 100%까지 올라갑니다.
A·B 구간이 있어야 켤 수 있고, 켜면 반복이 자동으로 시작됩니다.

## 5. 메트로놈

### 핵심: "영상에 동기화"

**영상에 동기화**(기본 켜짐) 상태에서는 메트로놈이 시계가 아니라 **영상의 재생 위치**를 따라갑니다.

- 영상을 멈추면 메트로놈도 멈추고, 재생하면 다시 박에 맞춰 나옵니다.
- 구간 반복으로 되돌아가거나 아무 곳으로 이동해도 박이 유지됩니다.
- 재생 속도를 70%로 늦추면 클릭도 자동으로 70% 빠르기가 됩니다.

동기화를 끄면 영상과 상관없이 혼자 도는 일반 메트로놈이 됩니다.

### BPM 입력란

큰 숫자는 **원곡 BPM**입니다. 그 아래 "실제 클릭 템포"는 현재 재생 속도를 반영한 값입니다 (예: 원곡 120 × 75% = 90).

- **− / ＋**: 1씩, **−0.1 / ＋0.1**: 0.1씩 조절
- **÷2 / ×2**: 박을 반이나 두 배로 (자동 감지가 반박·두 배로 잡혔을 때)

### 원곡 템포 맞추는 방법

**방법 1 — TAP (가장 확실함)**

1. 영상을 재생합니다.
2. **마디의 첫 박부터** 박자에 맞춰 TAP을 4번 이상 누릅니다 (PC는 `T` 키).
3. BPM과 박 위치(첫 탭 = 1박)가 함께 맞춰집니다.

느린 속도로 재생하면서 탭해도 원곡 BPM으로 자동 환산됩니다. 2초 이상 쉬었다가 누르면 새로 측정합니다.

**방법 2 — BPM 자동 감지**

곡을 12초 동안 듣고 BPM과 박 위치를 찾습니다. 끝나면 메트로놈이 자동으로 켜집니다.

- **PC (Chrome·Edge): 🎧 BPM 자동 감지** → 공유 창에서 **이 탭**을 고르고 **탭 오디오 공유**를 켜 주세요.
- **휴대폰: 🎤 BPM 자동 감지 (마이크)** → 마이크 권한을 허용하면 스피커 소리를 듣고 감지합니다. 조용한 곳에서 볼륨을 적당히 키워 주세요.

자동 감지는 박 간격은 잘 찾지만 **어느 박이 1박인지는 틀릴 수 있습니다.** 아래 "지금이 1박"으로 바로잡아 주세요.

### 싱크 포인트 — 곡 전체에서 박이 어긋나지 않게

탭이나 자동 감지로 맞춘 BPM에는 작은 오차가 있을 수 있습니다 (예: 실제 113인데 112.6).
맞춘 지점 근처에서는 괜찮지만, **멀리 이동하거나 처음으로 돌아가면 점점 어긋납니다.**
라이브 녹음처럼 템포가 조금씩 변하는 곡도 BPM 하나로는 맞출 수 없습니다.

이럴 때 **싱크 포인트**를 찍습니다.

1. 재생 중 마디의 1박에서 **지금이 1박 · 싱크 포인트 추가**를 누릅니다 (PC는 `D` 키).
2. 곡의 **처음, 중간, 끝** 등 여러 곳에서 반복합니다.
3. 이웃한 포인트 사이의 템포를 실제 곡에 맞게 계산하므로, 어디로 이동해도 박이 맞습니다. 템포가 변하는 곡도 구간마다 따라갑니다.

알아 두면 좋은 점:

- 버튼을 정확한 순간에 누르지 못해도 **가장 가까운 마디의 1박**으로 맞춰 주므로 박자가 통째로 밀리지 않습니다.
- 처음부터 너무 먼 곳을 찍기보다, **조금씩 범위를 넓혀 가며** 찍으면 더 정확합니다.
- 포인트는 타임라인에 주황색 ▲로 표시되고, 곡마다 저장됩니다.
- **되돌리기**는 마지막에 찍은 포인트를, **모두 지우기**는 전부를 지웁니다.
- BPM을 직접 바꾸거나, TAP·자동 감지로 다시 맞추면 기존 포인트는 지워집니다.

### 미세 조정 (-20ms ~ +20ms)

블루투스 이어폰 등으로 소리가 늦게 들리면 클릭이 음악과 살짝 어긋나 들릴 수 있습니다.

- 클릭이 음악보다 **빠르게** 들리면 **＋**
- 클릭이 음악보다 **느리게** 들리면 **−**

### 그 밖의 설정

| 설정 | 설명 |
|---|---|
| 박자 | 1 ~ 7박 (2/4, 3/4, 4/4, 5/4, 6/8, 7/8) |
| 쪼개기 | 박 사이에 작은 클릭을 추가 — 아래 표 참고 |
| 소리 | 비프 · 디지털 클릭 · 우드블록 · 클라베 · 스틱 · 림샷 · 카우벨 · 기계식 메트로놈 · 드럼(킥·스네어·하이햇) |
| 첫 박 강세 | 마디 첫 박을 더 높은 소리로 |
| 볼륨 | 메트로놈 소리 크기 (영상 소리와 별개) |

**▶ 한 마디 들어보기**를 누르면 지금 고른 소리와 쪼개기로 한 마디를 미리 들려줍니다. 소리를 바꿀 때도 자동으로 한 마디가 재생됩니다.

### 쪼개기 (리듬 패턴)

| 이름 | 한 박 안에서 | 이럴 때 |
|---|---|---|
| 없음 (4분) | 박만 | 기본 |
| 8분 | 반으로 똑같이 | 일반 8비트 |
| **8분 스윙 · 셔플** | 앞이 길고 뒤가 짧게 (♩♪ 셋잇단 느낌) | 블루스, 셔플, 재즈 스윙 |
| 셋잇단 | 셋으로 똑같이 | 6/8 느낌, 트리플렛 연습 |
| 16분 | 넷으로 똑같이 | 16비트, 펑크 |
| 16분 스윙 | 16분을 스윙으로 | 힙합·네오소울 그루브 |
| 갤럽 | 8분 + 16분 16분 | 메탈 갤럽 리프 |
| 역갤럽 | 16분 16분 + 8분 | 역갤럽 리프 |
| 점8분+16분 | 점8분 + 16분 | 튀는(바운싱) 리듬 |

- 선택하면 아래에 **패턴 그림**(큰 점 = 박, 작은 점 = 쪼갠 소리)이 나와 어떤 느낌인지 볼 수 있습니다.
- 스윙 패턴을 고르면 **스윙 정도** 슬라이더가 나타납니다. 50%는 똑같이(스트레이트), **67%는 셋잇단 셔플**(악보의 ♫ = ♩♪³ 표기), 75%는 점8분+16분 느낌입니다. 곡에 맞게 그 사이로 조절하면 됩니다.

화면의 동그라미 표시등이 박마다 깜빡이고, 첫 박은 진한 파란색으로 표시됩니다.

## 6. 단축키 (PC)

| 키 | 동작 |

## 7. 저장되는 정보

**곡마다** 다음이 자동 저장됩니다: A·B 구간, 저장한 구간 목록, BPM, 박 위치, 싱크 포인트, 재생 속도.
메트로놈 소리·박자·볼륨 같은 **설정**과 **최근 연 곡 목록**도 저장됩니다.

- 모두 **지금 쓰는 브라우저 안에만** 저장되고 서버로 보내지 않습니다.
- 그래서 PC에서 저장한 구간은 휴대폰에서 보이지 않습니다.
- 브라우저의 사이트 데이터(쿠키·저장소)를 지우거나 시크릿 모드로 열면 저장된 내용이 사라집니다.

## 8. 문제 해결

**"이 영상은 외부 재생(임베드)이 막혀 있어요"라고 나와요.**
영상 소유자가 다른 사이트에서의 재생을 막아 둔 경우입니다. 이 앱에서는 재생할 수 없으니, 같은 곡의 다른 영상(커버, 가사 영상 등)을 찾아보세요.

**휴대폰에서 메트로놈 소리가 안 나요.**
- 화면을 한 번 누른 뒤(▶ 등) 다시 켜 보세요. 휴대폰은 사용자가 화면을 눌러야 소리를 낼 수 있습니다.
- iPhone은 측면 **무음 스위치**를 확인해 주세요. 최신 iOS에서는 무음이어도 나오도록 처리했지만, 오래된 iOS에서는 소리가 안 날 수 있습니다.
- 메트로놈 볼륨 슬라이더가 0이 아닌지 확인해 주세요.

**메트로놈이 음악과 계속 어긋나요.**
1. **영상에 동기화**가 켜져 있는지 확인합니다.
2. TAP으로 다시 맞춥니다 (1박부터, 4번 이상).
3. 곡의 여러 곳에서 **싱크 포인트**를 찍습니다.
4. 일정하게 조금씩 어긋나 들리면 **±ms 미세 조정**을 씁니다.

**자동 감지 BPM이 반이나 두 배로 나와요.**
**÷2 / ×2** 버튼으로 바로잡으세요. 1박 위치는 **지금이 1박**으로 맞춥니다.

**휴대폰에 "🎧 BPM 자동 감지(탭 오디오)" 버튼이 없어요.**
탭 오디오를 듣는 기능은 PC의 Chrome·Edge에서만 지원됩니다. 휴대폰에서는 마이크 감지나 TAP을 써 주세요.

**연습 중에 화면이 꺼져요.**
영상이 재생되는 동안에는 화면이 꺼지지 않게 해 두었습니다. 일부 브라우저(특히 오래된 버전)에서는 지원되지 않을 수 있습니다.
